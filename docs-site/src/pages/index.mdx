# Define languages, not interpreters

KRS is a declarative language for writing programming-language semantics in Rust.
You declare syntax, machine state, rewrite rules, static semantics, and verification claims; KRS checks and lowers that definition for the K toolchain.

The dependency-ordered tour grows IMP, a small imperative language with expressions, variables, and control flow, then explains lowering, verification, large state configurations, composition, and current boundaries.
Its final five-minute synthesis compresses the model back to one rewrite—`foo` becomes `bar`—with generated explanations for direct readers.

[Start with what KRS defines →](/start/what-krs-defines)

This site also documents [k-rust](/k-rust), the Rust implementation of K that KRS lowers through.

:::info
The tour documents the current implementation.
Qualified features are labeled with their exact boundary, and proposed syntax is kept on the boundaries pages rather than presented as usable KRS.
:::
