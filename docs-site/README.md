# KRS language tour site

This directory contains the dependency-ordered language tour and its generated-gloss five-minute synthesis page.
The site uses Vocs 2.8.5 and Bun 1.3.13.
Install its locked dependencies with `bun install --frozen-lockfile`.
Run the local site with `bun run dev` and its fixture/tooling gate with `bun run check`.
Waku is pinned to `1.0.0-beta.6` because Vocs 2.8.5 uses that router event contract; widening the prerelease range resolves to `1.0.0-rc.0` and crashes `ScrollRestoration` after hydration.
It verifies that the displayed `tour-minimal` mirror is byte-for-byte identical to its authoritative fixture and that the fixture passes `cargo check --locked`.
The primary navigation contains all 17 canonical chapters from `docs-plan/tour.toml` plus the checked five-minute synthesis.
Its hover/focus glosses and canonical destinations are generated from the ledger rather than copied into a second glossary.
`bun run check` validates the curriculum, reviewed public surfaces, complete page graph and anchors, generated compatibility and port summaries, terminology, gloss accessibility contracts, synced snippets, Rust-Twoslash failure controls, and the authoritative Cargo/KRS fixtures.
`bun run check:types && bun run build` is the production release gate, including Vocs dead-link checking.

Rust Twoslash is supplementary.
Enable it with `KRS_RUST_TWOSLASH=1 bun run build` only after `bun run check:twoslash` passes.
The Twoslash gate fails on a missing or broken binary, a subprocess failure, nonzero status, invalid protocol output, analyzer diagnostics, or failure to see the `M2Obj` symbol generated by a KRS procedural macro.
It materializes Cargo metadata with absolute path dependencies, so the analyzer's temporary project does not reinterpret paths relative to its temporary directory.
The materialized compiler check copies the fixture lockfile and runs locked and offline.
The preflight and Vocs resolve the same binary through the installed `@vocs/twoslash-rust` package.

The current `@vocs/twoslash-rust` 0.1.0 backend disables procedural-macro expansion.
Consequently the generated-symbol probe is expected to fail until that upstream capability is fixed; leave `KRS_RUST_TWOSLASH` unset in the meantime.
The ordinary fixture compiler gate remains mandatory in both modes.

Twoslash result-cache reuse is intentionally disabled by using a fresh cache directory for every build.
This avoids the upstream cache key, which does not include the Cargo manifest, lockfile, tool versions, or dependency sources.
The fail-closed gate also runs on every enabled build rather than trusting cached success.
