# F2 examples

The texts' `Source` attributes are relative (`test/relsource.py`): a file of this tree as `kcore-spec/…` (or another
directory beside kcore-spec), a file elsewhere in the k-rust checkout relative to it (`kink/…`, `imp-semantics/…`), K's
builtin files as kompile wrote them. kompile writes absolute paths; each text was rewritten after kompiling, so a text
said below to be byte-identical to another kompile run is identical to it up to those paths. The reader takes from a
`Source` whether it is a builtin file's and whether it is the main module's, both kept by the rewrite, and the string
itself only into the presentation (for `emit`).

- `prio.k`, `prio.kore`: the probe of F2's priorities, an `[owise]` rule and a diamond of subsorts; in KCore by the kernel (its generated package's tie, `examples/prio`, KCORE-SPEC.md §12).
- `imp.kore`: kink's IMP, `krust kcompile kink/examples/imp/imp.k --main-module IMP -w none` (k-rust checkout, `imp.k` unchanged since commit acda502cc). Byte-identical to the corpus copy the M3.0 and M3.2 runs used (`findings/work/kore/kink-examples-imp-imp-imp/definition.kore`, which is not tracked), and to a fresh kompile on 2026-11-09. Its `Source` attribute names `imp.k` relative to the checkout (`kink/examples/imp/imp.k`). In F2 by the compiled check (`findings/work/m32/diag.sh`); not by the kernel (findings/M3.2-f2-landing.md §5).
- `imp-programs.kore`: kink's seven IMP programs (`kink/examples/imp/programs/*.imp`, in file-name order: and, arith, collatz, divzero, primes, redeclare, sum) as KORE patterns of sort `Pgm`, one per line; a copy of `m3-spec/diff/pgm/kink-examples-imp-imp-imp.kore` (`m3-spec/diff/programs.sh`: `krust kast`, then `kast2kore.py`).

- `kimp.kore`: kimp, Runtime Verification's `imp-semantics` (`src/kimp/kdist/imp-semantics/imp.k`, main module IMP, syntax module IMP-SYNTAX), by `test/ni-kore.sh`; byte-identical to the corpus copy (`findings/work/kore/imp-semantics-src-kimp-kdist-imp-semantics-imp-imp/definition.kore`). In F2 (compiled check).
