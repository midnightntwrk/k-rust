How to read the AML column:

- Every translated axiom has the form `ws → (AML2(φ) = ⟦s⟧)` ([Thesis] (7.10)): `ws` guards the axiom's sort variables (`R ∈ ⟦Sort⟧`) and its free variables (`X0 ∈ ⟦SortK⟧`, `@X ⊆ ⟦SortMap⟧`).
- `⟦s⟧` is the inhabitant pattern `⊤_ s`; `=`, `∈`, `⊆`, `⌈_⌉` without brackets are AML's unsorted definedness notations (aml-port `Definedness.lean`).
- A bracketed sort marks a sorted notation, the AML image of an MmL construct: `¬[s] φ ≡ ¬φ ∧ ⟦s⟧` (7.16); `φ ∨[s] ψ`, `φ →[s] ψ`, `⊤[s]`, `⊥[s]` (2.95)–(2.97); `∃x:s. φ ≡ ∃x. x ∈ ⟦s⟧ ∧ φ` (7.17); `⌈φ⌉[s,s']` is the symbol `ceil` applied to `s s' φ` (2.98); `φ =[s,s'] ψ`, `φ ∈[s,s'] ψ` (2.101), (2.102).
  The printer shows a notation only when the pattern is exactly that notation's definition (it rebuilds the notation from the parts and compares).
- Sort names are KORE's; symbol names drop `Lbl` and are unmangled for display (`'Unds'` ↦ `_`, `'-LT-'k'-GT-'` ↦ `<k>`); variable names likewise (`Var'Unds'Gen0` ↦ `Var_Gen0`).
- Application is juxtaposition: `inj SortNat SortVal From` is `inj{SortNat{}, SortVal{}}(From)` (S-args).
